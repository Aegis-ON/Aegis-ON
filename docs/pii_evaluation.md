# 합성 개인정보 구간 평가

이 평가는 공격 탐지 평가와 별개의 **작은 합성 개인정보 구간 회귀 평가**입니다. 실사용 데이터의 개인정보 탐지율이나 실제 환경의 성능을 입증하지 않습니다. 예제는 만들어낸 이름, `example.test` 이메일과 문서용 IP 주소를 사용합니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```bash
PYTHONPATH=src python -m aegis_on.pii_evaluation --dataset evaluation/pii_synthetic_v1.json
```

선택적으로 `--output report.json`으로 결과를 저장할 수 있습니다. 평가 자체는 모델을 다운로드하지 않습니다. 설정된 모델이 준비되지 않았거나 실행 중 오류가 발생하면 `model_only.available`이 `false`, 해당 점수는 `null`이며 이유를 표시합니다. 모델 오류 시 부분 점수나 가상의 수치를 내지 않습니다. 모델 설치·설정은 [PII 탐지기 문서](pii_model.md)를 참조하세요.

## 데이터와 범위

`pii-synthetic-v1`은 한국어·영어 문맥의 인위적인 입력과 수동으로 지정한 정답입니다. 이름, 이메일, 한국·해외 전화번호, IPv4·IPv6, 개인정보가 없는 텍스트, 반복 구간과 긴 문장을 포함합니다. 정답 인덱스는 Python의 Unicode 코드포인트 기준이며 `start`는 포함, `end`는 제외입니다. 이름을 성과 이름으로 분리한 경계는 이 데이터에서만 정한 것입니다. 공백 없는 한국어 성·이름 분리나 영어 이름 순서는 실제로 더 모호할 수 있습니다. 모델의 다른 레이블(사용자 이름, 주소 등)은 이 데이터에서 완전하게 주석하지 않아 평가에서 제외합니다.

| 레이블 | 예시 유형 | 정규식 공통 비교 | 모델 추가 비교 |
| --- | --- | --- | --- |
| EMAIL | 이메일 주소 | 포함 | 포함 |
| TELEPHONENUM | 전화번호 | 포함 | 포함 |
| IP_ADDRESS | IP 주소 | 포함 | 포함 |
| GIVENNAME | 이름 | 제외 | 포함 |
| SURNAME | 성 | 제외 | 포함 |

정규식 기준선과 모델은 같은 텍스트로 평가합니다. `regex_baseline.common`과 `model_only.common`은 공통 세 레이블로 비교합니다. `model_only.all_annotated`에는 이름 레이블을 추가합니다. 공통 범위를 벗어난 예측은 공통 점수에서 제외하므로 전체 개인정보 탐지에 대한 오탐률로 해석하면 안 됩니다. 모델만의 점수에는 `source=model` 구간만 사용하고 정규식 결과를 합산하지 않습니다. 이 데이터는 18개 모델 레이블 전체를 평가하지 않습니다.

## 계산과 해석

정답과 예측의 시작, 끝, 레이블이 모두 일치하면 TP입니다. 일치하지 않는 예측은 FP, 일치하지 않는 정답은 FN입니다. 같은 정확한 예측이 반복되면 한 구간으로 계산합니다. 서로 겹치는 다른 예측은 각각 판단합니다. 부분 일치나 다른 레이블의 일치는 TP가 아니며 FP와 FN을 모두 만들 수 있습니다. 데이터 정답은 서로 겹치지 않도록 검증합니다. 예측이 겹치는 경우는 별도 테스트로 검증합니다.

전체 및 레이블별 TP·FP·FN, 정답 구간 수인 `support`, precision, recall, F1을 제공합니다. 분모가 0이면 해당 값은 `null`이고 `undefined_reason`을 표시합니다. 오탐·미탐 사례 ID는 입력 데이터의 `cases` 배열 순서에 따라 `case-0001`, `case-0002`처럼 만들어집니다. 로컬 데이터 파일에서 해당 순서의 사례와 대조할 수 있으며 배열 순서가 바뀌면 표식도 바뀝니다. manifest에 적힌 사례 ID는 출력하지 않습니다. 목록은 중복 없이 표시하므로 목록 길이는 구간 수와 다를 수 있습니다. 데이터셋 ID도 입력 문자열을 직접 출력하지 않고 SHA-256 해시 표식으로 표시합니다. 출력에는 입력 원문, 예측 문자열, 구간 위치 또는 정답 문자열이 없습니다. 데이터 파일 자체에는 합성 원문이 들어 있습니다.

모델 비활성 상태에서 17개 합성 사례를 실행했을 때, 공통 세 유형의 정규식 결과는 TP 15, FP 0, FN 2, precision 1.0, recall 약 0.8824, F1 0.9375였습니다. 미탐 두 사례는 공백이 포함된 전화번호와 해외 전화번호입니다. 이 수치는 해당 합성 구간에만 적용됩니다. 실제 모델 파일을 실행하지 못했으므로 모델 점수는 측정하지 않았습니다.

이 데이터는 표본이 작고 개발 중 공개되어 있으며 실제 개인정보의 언어, 형식, 빈도, 문맥과 분포를 대표하지 않습니다. 긴 문장과 일부 반복 사례만으로 모델의 모든 길이·경계 처리를 검증할 수 없습니다. 공정한 최종 성능 비교에는 별도로 수집·검토한 대표성 있는 미사용 데이터와 명확한 주석 기준이 필요합니다. 예제 전체를 반복 평가해 얻은 결과를 독립적인 검증 결과로 사용하지 마세요.
