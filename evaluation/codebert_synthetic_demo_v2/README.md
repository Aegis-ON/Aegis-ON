# Aegis-ON CodeBERT 아이디어톤 합성 데이터 384건

6개 업무 영역에서 Sysmon Event ID 1 형식의 시나리오 48개를 만들었다. Codex가 사례마다 정상·추가 조사·판단 보류 라벨과 한글 판정 근거를 작성했다. 명령 문자열은 실행하지 않았다.

| 분할 | 전체 | 그룹 | 정상 | 추가 조사 | 판단 보류 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 학습 | 272 | 34 | 102 | 102 | 68 |
| 검증 | 56 | 7 | 21 | 21 | 14 |
| 평가 | 56 | 7 | 21 | 21 | 14 |
| 합계 | 384 | 48 | 144 | 144 | 96 |

기존 파일럿 128건은 별도 자료로 보관하며 두 패키지의 인벤토리 합계는 512건이다. 신규 패키지에는 프로세스 실행파일 25종과 정규화 후 고유 명령줄 380개가 있다. 가상 업무 맥락이 다른 보류 사례 쌍 4개는 동일 그룹에 뒀다. PowerShell은 226건이다. npm 배치 스크립트 사례는 `cmd.exe`를 실행파일로 기록한다.

| 파일 | 내용 |
| --- | --- |
| `scenario-matrix.jsonl` | 그룹별 업무 범위와 판단 기준 |
| `events.jsonl` | Sysmon 형식의 합성 로그 |
| `labels.jsonl` | 사례별 라벨과 명령 계열 |
| `label-evidence.jsonl` | `case_id`별 판정 근거 |

분할 파일과 체크섬은 [CodeBERT 전처리 절차](../../docs/codebert_shadow.md)의 `prepare` 명령에 `--fixture`를 지정해 생성한다.

`review`는 추가 조사 필요를 뜻한다. 업무·승인 맥락은 근거에 저장하며 CodeBERT 입력은 명령줄이다. `unknown`은 이진 분류 학습과 평가 지표에서 제외한다. 이 자료의 사용 범위는 아이디어톤 합성 시나리오다.
