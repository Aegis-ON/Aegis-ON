분석 개요

Sysmon 이벤트와 탐지 근거를 한눈에 확인합니다.

샘플은 합성 데이터이며 버튼을 누르면 실제 탐지 API로 분석합니다. 규칙·키워드 및 선택적 실험용 모델 결과를 구분하며, 탐지 점수는 공격 확정을 의미하지 않습니다.

분석 시작

합성 시나리오 또는 Sysmon JSON 파일을 선택하세요. 분석 요청에는 API 토큰이 필요합니다.

분석 안내

결과를 해석하기 전에 확인하세요.

탐지 방식
명령줄 분석은 규칙·키워드 기준선과 선택적 실험용 BERT 모델을 구분합니다. 키워드 기준선은 BERT가 아닙니다. 개인정보 탐지는 별도 기능입니다.

개인정보 탐지의 한계
탐지 및 가명처리는 모든 개인정보를 보호하지 못하며 누락될 수 있습니다.

연결 상관분석
같은 호스트가 10분 이내 서로 다른 목적지 3곳 이상에 발신한 이벤트를 표시합니다. 수신·방향 미상은 제외하며 스캔이나 공격을 확정하지 않습니다.

승인
승인은 시뮬레이션 상태만 기록합니다. 단말 격리나 네트워크 차단은 수행하지 않습니다.

탐지 및 이벤트

선택한 분석 결과
분석을 시작하면 결과와 이벤트 근거가 여기에 표시됩니다.

로컬 분석 이력

이력에는 가명처리된 식별 정보와 승인 시뮬레이션이 저장됩니다. 실제 차단은 수행하지 않습니다.

인증 후 이전 분석을 조회할 수 있습니다.

로컬 이력은 민감할 수 있습니다. 원본 로그 전체는 저장하지 않지만 개인정보 탐지의 누락으로 일부 값이 남을 수 있습니다.
