# 조사 메모 — CASE-NORMAL-CANDIDATE-20261121-01

## 정상 비교 후보의 근거

`/health`에 대한 HTTP 200 요청 한 건이 통제 ARTEX 실습보다 앞선 같은 환경에서 기록됐다. 이 경로는 일반적인 상태 점검 경로와 일치하므로 비교 후보로 보존한다.

그러나 다음 두 가지는 증거에 없다.

- 이 요청을 만든 모니터링 도구 또는 운영자
- 해당 작업의 승인 티켓·변경 기록

따라서 이 묶음은 “정상”이 아니라 **정상 후보**다. 보안팀은 원본 출발지와 승인 기록을 확인한 후에만 정상 라벨로 승격해야 한다.

## 비교 시 유의점

- 사례와 비교 후보 모두 같은 `SERVICE-WEB-01`의 접근 로그를 사용한다.
- 요청 ID와 출발지는 가명이다. 두 가명은 서로 다른 원래 식별자를 뜻하지만, 실제 원값은 이 공유본에 넣지 않았다.
- Sysmon Event ID 1·3은 UTC `09:47:00Z`–`09:52:00Z` 원본 구간을 직접 조회해 각각 0건이었다. 활성 규칙이 `testCurl.exe`만 포함했으므로, 이 빈 배열을 근거로 엔드포인트 행위를 비교하면 안 된다.
